# Tora Sandhi Kamulian — Game Programmer Portfolio

A static Unreal Engine / gameplay programming portfolio built for GitHub Pages. It uses plain HTML, CSS, and minimal JavaScript—there is no build step or backend.

## Local preview

Open `index.html` directly, or serve the folder with any simple static web server.

## Publish with GitHub Pages

1. Push the contents of this repository to your GitHub repository.
2. In GitHub, open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose your default branch (usually `main`), select the `/ (root)` folder, and save.

GitHub will show the published URL after deployment finishes.

## Before publishing

- Add three current Carnifall screenshots following `assets/README.md`.
- Keep the generated CV at `output/pdf/Tora-Sandhi-Kamulian-CV.pdf` so both download links remain valid.
- Update the Email or GitHub links in `index.html` if those contact details change.

Do not add proprietary source code, private project files, or media you do not have permission to publish.
